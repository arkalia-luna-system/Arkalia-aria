## Deprecation Policy - ARKALIA ARIA

Date d'effet : 27 avril 2026

### Statut
- Projet déprécié en faveur de `arkalia-cia`.
- Support limité pendant la période de migration.

### Timeline
- **Phase 1 (immédiate)** : gel des nouvelles features ARIA.
- **Phase 2 (transition)** : migration des composants utiles vers CIA.
- **Phase 3 (fin de vie)** : archivage complet du dépôt ARIA.

### Compatibilité
- Les APIs ARIA peuvent rester accessibles temporairement pour migration.
- Les contrats cibles doivent être consolidés dans CIA.

### Attendu pour les contributeurs
- ouvrir les nouveaux développements dans CIA,
- utiliser ARIA uniquement pour référence historique ou extraction de logique à migrer.
