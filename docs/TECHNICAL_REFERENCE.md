## Référence Technique ARKALIA ARIA

Ce document regroupe les informations techniques essentielles pour les développeurs qui vont plus loin que le simple guide développeur.

- **Architecture principale** : voir `PROJECT_STATUS.md` pour la vue d’ensemble et les métriques de migration.
- **Modules clefs** : `core/`, `pain_tracking/`, `pattern_analysis/`, `prediction_engine/`, `health_connectors/`, `cia_sync/`, `metrics_collector/`.
- **Normes de qualité** : linting avec Ruff, typage avec MyPy, formatage Black, vérifications de sécurité avec Bandit et Safety.

Pour les détails de chaque endpoint, se référer à `API_REFERENCE.md`. Pour l’état technique détaillé par module, se référer à `MODULE_STATUS.md`.
